Parser: month-first parsing for day-first tenants

The shared parser reads dates month first even when the tenant’s locale uses day first. Ambiguous dates can swap month and day. Scope is determined by causeOf in src/lib/kb/causes.ts, using the tenant directory and channel, not meta.intakeTag. Preserve the tenant’s date interpretation throughout booking, invite and reminder handling.

Hint: booking-v3 prints a month-first example for day-first tenants

The booking-v3 date field advertises MM/DD/YYYY while the form reads a day-first tenant’s entry in the tenant’s order. Users following the hint get a wrong result through a distinct input path. Align the visible hint with the form’s parsing contract; a shared-parser fix alone does not demonstrate that this form defect is fixed.
